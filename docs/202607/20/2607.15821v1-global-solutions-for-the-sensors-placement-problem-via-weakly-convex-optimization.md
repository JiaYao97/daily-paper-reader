## 摘要
我们研究了在未知底层动力学的情况下，优化布置有限数量的传感器以重建高维信号的问题。该任务被表述为一个非凸组合优化问题，并重新构建为一个弱凸约束投影问题。这种重构使我们能够使用非精确切割球算法计算$\varepsilon$-全局解。我们进一步提出了逆切割球算法，该算法从任何可行的启发式解开始，要么通过指定的容差$\varepsilon$改进它，要么验证其$\varepsilon$-全局最优性。该框架在使用XFOIL数据的NACA翼型压力重建中进行了评估。

## Abstract
We address the problem of optimally placing a limited number of sensors to reconstruct high-dimensional signals without knowledge of the underlying dynamics. The task is formulated as a nonconvex combinatorial optimisation problem and recast as a weakly convex constrained projection problem. This reformulation allows us to compute $\varepsilon$-global solutions using the Inexact Cutting Sphere algorithm. We further propose the Inverse Cutting Sphere algorithm, which starts from any feasible heuristic solution and either improves it by a prescribed tolerance $\varepsilon$ or certifies its $\varepsilon$-global optimality. The framework is evaluated on pressure reconstruction for NACA airfoils using XFOIL data.
