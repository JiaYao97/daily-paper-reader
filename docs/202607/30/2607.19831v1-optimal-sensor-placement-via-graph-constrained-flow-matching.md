## 摘要
最优传感器布局是图信号处理（GSP）中的一个基本问题，其中部署有限数量的传感器以重建连续信号场。现有的GSP方法依赖于离散化图上的组合优化，导致计算成本高且传感器位置局限于图顶点。我们将传感器布局重新表述为一个连续空间生成建模问题。离线GSP优化例程首先生成最优传感器配置的训练样本，然后流匹配（FM）模型学习其分布。在推理时，学习到的速度场直接生成连续的传感器坐标，消除了在线组合优化。我们进一步开发了一个置换不变的条件生成框架，用于固定锚定传感器的部署。在真实无线电传播模拟器上的实验证明了所提框架在传感器布局中的有效性。

## Abstract
Optimal sensor placement is a fundamental problem in graph signal processing (GSP), where a limited number of sensors are deployed to reconstruct a continuous signal field. Existing GSP methods rely on combinatorial optimization over discretized graphs, resulting in high computational cost and sensor locations restricted to graph vertices. We reformulate sensor placement as a continuous-space generative modeling problem. An offline GSP optimization routine first generates training samples of optimal sensor configurations, from which a flow matching (FM) model learns their distribution. At inference, the learned velocity field directly generates continuous sensor coordinates, eliminating online combinatorial optimization. We further develop a permutation-invariant conditional generation framework for deployment with fixed anchor sensors. Experiments on a realistic radio propagation simulator demonstrate the effectiveness of the proposed framework for sensor placement.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：在连续空间区域中，如何利用有限数量的传感器部署位置，使得从这些传感器观测值重建全局信号场的误差最小。这是一个经典的“最优传感器放置”问题，广泛应用于环境监测、无线通信、无人机编队等领域。
- **现有方法的局限**：传统图信号处理（GSP）方法将连续区域离散化为图，然后在图节点上使用组合优化（如贪心算法）选择传感器位置。这导致两个主要缺陷：
  - 计算成本高（每次部署都需要重新优化，且复杂度与图大小 \(n\) 相关，通常 \(n \gg k\)）。
  - 传感器位置被限制在图顶点上，无法实现连续空间中的任意位置，限制了性能。
- **本文的创新意图**：将传感器放置从“离散组合优化”范式转换为“连续生成建模”范式，利用生成模型直接输出连续坐标，从而绕过在线组合优化，实现超分辨率、离网格的推理。

## 2. 方法论

- **核心思想**：学习最优传感器配置的分布，而不是直接求解优化问题。具体流程分为两个阶段：

  - **离线阶段（训练）**：
    1. 构造一个离散化图 \(G\)（由 Voronoi 划分生成，节点数 \(n \gg k\)）。
    2. 从信号分布 \(\mu\) 中采样 \(m\) 个图信号，使用带正则项的贪心算法（公式 (5)）选择 \(k\) 个传感器位置。重复 \(T\) 次，得到训练集 \(S = \{P^{(1)},\ldots,P^{(T)}\}\)。
    3. 将图节点坐标视为连续空间中的点，训练一个流匹配（Flow Matching, FM）模型。FM 学习一个时间依赖的速度场 \(u_\theta(t, x)\)，将高斯噪声转化为目标传感器配置分布。训练损失为条件流匹配损失：\(L_{\text{FM}} = \mathbb{E}[\|u_\theta(t, x_t) - (x_1 - x)\|^2]\)，其中 \(x_t = t x_1 + (1-t)x\)。

  - **在线阶段（推理）**：
    1. 从噪声分布采样初始传感器坐标 \(P_0\)。
    2. 若存在固定锚定传感器集合 \(P_{\text{fix}}\)，使用匈牙利算法将初始坐标与锚点匹配，并通过 sigmoid 混合方案逐步将匹配传感器引导至锚点。
    3. 未匹配的传感器自由演化，最终输出连续坐标 \(P_1\)。
  - **关键技术细节**：
    - 使用 **Point Transformer** 作为速度场的编码器，实现置换等变性（permutation equivariance），确保传感器集合的无序性。
    - 条件生成中采用 **线性分配 + sigmoid 混合** 来保证锚点约束，避免索引混淆。
    - 速度场基于多头注意力机制，使每个传感器的速度取决于与其他传感器的空间关系。

- **公式说明**：训练 FM 时，条件流匹配损失为 \(\mathbb{E}_{t, \mu_t(x)}\|u_\theta(t, x) - u_t(x)\|^2\)，其中 \(u_t(x|x_1) = x_1 - x\)。

## 3. 实验设计

- **数据集/场景**：基于文献 [17] 的无线电传播模拟器，设定一个平坦的 2D 区域 \(\Omega\)，内有 3 个无线发射机，其位置服从混合高斯分布（提供三种分布：triangle、Lshape、diagonal）。信号受路径损耗、阴影衰落、快衰落和加性高斯噪声影响。目标：部署 10 个传感器，其中 5 个为预定义锚点。
- **基准方法**：
  - **GB**：使用离线 GSP 贪心算法（无锚点约束）得到的最佳配置，作为“黄金基线”。
  - **SF**：锚点从 GB 样本中选取，其余 5 个传感器由本文 FM 方法生成。
  - **SP**：锚点同 SF，其余传感器使用 PRODIGY（一种受约束的图生成模型）生成。
  - **RF**：锚点随机选取，其余传感器由 FM 生成。
  - **SR**：锚点从 GB 样本中选取，其余传感器随机放置。
