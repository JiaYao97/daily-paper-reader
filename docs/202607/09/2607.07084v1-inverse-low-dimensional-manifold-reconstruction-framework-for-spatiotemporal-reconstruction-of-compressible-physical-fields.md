## 摘要
可压缩物理场在真实物理世界中广泛存在，但当前人工智能缺乏对可压缩物理场中不可微特征的理解机制。针对现有深度学习架构在处理全局不可微特征方面的局限性，我们提出了逆低维流形重构框架（ILDM）。该框架将捕获可压缩流中不可微特征的不可微逼近函数（NAF）与专为光滑流体区域设计的光滑流体重构模块（SFR）耦合。通过在包含黎曼问题和双马赫反射的一维与二维基准测试上的广泛评估，结果表明ILDM显著优于cPINN和R-adaptive DeepONet。具体而言，ILDM实现了不可微界面的优越定位，并即使在低分辨率输入下也能保持稳健的超分辨率性能，为数据驱动的流体动力学建立了一种物理一致且可扩展的范式。

## Abstract
Compressible physical fields are widely present in the real physical world, but current artificial intelligence lacks an understanding mechanism for the non-differentiable features in compressible physical fields. Addressing the limitations of existing deep learning architectures in handling global non-differentiable features, we propose the Inverse Low-Dimensional Manifold reconstruction framework (ILDM). This framework couples the Non-differentiable Approximation Function (NAF) for capturing non-differentiable features in compressible flows with the Smooth Fluid Reconstruction (SFR) module tailored for smooth fluid regions. Extensive evaluations across 1D and 2D benchmarks, including Riemann problems and double Mach reflection, demonstrate that ILDM significantly outperforms cPINN and R-adaptive DeepONet. Specifically, ILDM achieves superior localization of non-differentiable interfaces and maintains robust super-resolution performance even with low-resolution inputs, establishing a physically consistent and scalable paradigm for data-driven fluid dynamics.

- **研究动机**：可压缩物理场（如激波、接触间断）中广泛存在**非可微特征**（如间断、尖点），这些特征对传统数值方法和现有深度学习模型（如 PINN、DeepONet）构成巨大挑战。现有架构（如 cPINN、R-adaptive DeepONet）要么需要手动指定子域边界，要么本质上只能逼近光滑算子，难以全局重构具有快速移动非可微界面的复杂流场。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：将可压缩物理场分解为**非可微界面**与**光滑流体区域**的线性叠加，分别设计专用模块，并通过逆低维流形映射实现非可微界面的逐步升维重构。
- **关键模块**：
  - **非可微逼近函数（NAF）**：
    - 基于两个方向相反 Sigmoid 函数的乘积，引入梯度缩放因子（\(\varphi, \phi\)）和峰值系数 \(v_i\)，构造形式为：
      \[
      F(x; v_i, x_i, \varphi, \phi) = v_i \cdot \sigma_{\varphi}(x - x_i) \cdot (1 - \sigma_{\phi}(x - x_i))
      \]
      （其中 \(\sigma_{\varphi}(x) = 1/(1+e^{-\varphi x})\)）
    - 通过调节缩放因子可同时逼近**间断型**（两侧梯度均突增）和**连续但不可微型**（单侧梯度突增）界面。
    - 非可微点位置 \(x_i\) 和高度 \(v_i\) 的时序演化由 MLP 学习。
  - **逆低维流形重构（ILDM）**：
    - 将非可微界面视为嵌入在 \(n\) 维空间中的 \((n-1)\) 维 Lipschitz 流形，非可微曲线和点分别是其 1D 和 0D 子流形。
    - 通过 NAF 构造水平集映射 \(\Phi\)，实现从点→曲线→界面的渐进升维重构，保证几何正则性和拓扑一致性。
  - **光滑流体重构模块（SFR）**：
    - 利用已识别的非可微界面作为掩模，分离出光滑流体区域。
    - 采用 ConvLSTM 作为核心网络，提取空间形态特征并捕获时间演化动态。也可无缝集成 U-Net、FNO 等其他模型。
- **整体流程**：
  1. 利用 NAF 和 ILDM 重构任意时刻的非可微界面 \(D_k\)。
  2. 利用 SFR 模块重构光滑区域 \(C_k\)。
  3. 叠加 \(D_k + C_k\) 得到完整可压缩流场 \(U_k\)。
