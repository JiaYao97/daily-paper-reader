Abstract 

We propose Variance-Preserving Orthogonal Selection (VPOS) , a greedy framework for unsupervised feature selection that operates in the weighted PCA loading space. After each selection, VPOS projects out the chosen feature’s variance direction via null-space deflation, forcing subsequent selections to cover orthogonal parts of the covariance structure. Each step provably reduces the loading matrix rank by one, and the greedy objective connects to monotone submodular maximization. The single hyperparameter d is selected via a reproducible rule: the value minimising reconstruction MSE in a sensitivity sweep. On eight benchmarks, VPOS achieves the lowest reconstruction MSE on all eight while running 10– 140 × faster than graph-based methods at scale. Comparing against PCA (no deflation) at matched d confirms deflation as the primary driver, reducing MSE by 10–73%. 

Keywords: unsupervised feature selection, principal component analysis, orthogonal deflation, column subset selection, greedy algorithms, gene expression 

1. Introduction 

Dimensionality reduction transforms high-dimensional data into a lower-dimensional space by extracting meaningful patterns or selecting the most relevant features. Dimension-ality reduction is broadly categorized into feature selection and feature extraction. Feature selection selects a subset of unchanged input features according to predefined evaluation met-rics, while feature extraction applies mathematical transformations to the high-dimensional data and transforms it into a compressed, lower-dimensional space while maximizing the retention of critical variance. We focus on unsupervised feature selection : selecting a dis-crete subset of original features based solely on the intrinsic variance structure of the data, without access to class labels. This setting excludes supervised methods (wrapper and em-bedded approaches) that require a target variable, as well as feature extraction methods

In genomics, finance, and clinical measurement, the goal is not a rotated projection but the identification of a small, interpretable set of original variables — specific genes, assets, or biomarkers — that capture the essential vari-ance structure. Gene-expression microarrays are a canonical example: thousands of genes are measured simultaneously, but only a handful of pathway-level signals drive biological variation, and practitioners need to identify the specific genes to target in follow-up assays [25]. Unsupervised feature selection fills this role, yet it faces a structural difficulty [3]. Most methods assign each feature an independent score (marginal variance, Laplacian score [4], spectral score [5]) and select the top k. Under strong multicollinearity, the top-k features all correspond to the same dominant latent factor, giving a redundant subset that misses independent secondary and tertiary signals entirely. We call this the clustering trap .A separate line of work sidesteps discrete selection by placing ℓ1 penalties on PCA load-ings [8, 9]. These methods produce sparse component weights, not a discrete feature index set. In applications where practitioners need to physically act on selected variables — con-structing a portfolio, running a targeted assay — mixing originals is not acceptable. The Clustering Trap in Static Selection 

Static ranking methods assign a scalar score to each feature independently and select the top-k features by score. Under extreme multicollinearity—where a dominant latent factor drives many features—the top-k features by any static criterion (variance, Laplacian score [4], spectral score [5]) will all correspond to the same latent factor. This is the clustering trap : the selected subset is informationally redundant, and lower-variance but independent latent factors are entirely missed. VPOS resolves this by making the selection criterion adaptive: the score of each candidate feature is updated after every selection to reflect only the variance not yet explained by the already-chosen set.

Role of d. The hyperparameter d controls which part of the covariance structure VPOS operates on, and its effect is not symmetric. When d is too small, B is an overly compressed summary that conflates distinct latent directions; the deflation drains correlations inaccu-rately, and the selected features do not fully escape redundancy. When d is too large — particularly when d approaches N or includes PCs whose eigenvalues are near-zero — the loading vectors for those trailing components are dominated by estimation noise. Deflat-ing along noise directions injects randomness into the scoring sequence, degrading selection quality. The practical sweet spot is d near the data’s intrinsic dimensionality — enough to represent the main covariance structure faithfully, but not so large as to include noise components. 

Selection rule for d. We adopt a reproducible, single-criterion rule: sweep d over a representative range (5–6 values spanning the plausible signal dimensionality) and select the d that minimises reconstruction MSE on the VPOS-selected features. This criterion is consistent with VPOS’s design objective of maximising variance coverage. The sensitivity analysis in Section 6.4 reports both MSE and kNN accuracy across the sweep; the minimum-MSE rule is the formal selection criterion, and all VPOS results in Table 1 use this best-d.

Complexity. The eigendecomposition costs O(D2N +D3). Each deflation step costs O(Dd ),and scoring costs O(Dd ) per iteration, giving a total selection phase cost of O(kDd ). For large D, a randomized SVD [17] can reduce the decomposition to O(DN log d).54. Related Work 

Since VPOS is an unsupervised method that selects discrete original features based on variance structure, we restrict this survey to methods in the same problem class. We exclude supervised approaches (wrapper and embedded methods) that require a target variable. We also exclude several important nonlinear feature extraction methods such as autoencoders, kernel PCA, and UMAP, as they produce transformed representations rather than origi-nal feature subsets. Within unsupervised feature selection, methods fall into four families: spectral/graph-based, sparse PCA, reconstruction-driven, and matrix factorization/deflation methods. We survey the most relevant prior work in each and clarify where VPOS sits. 

4.1. Spectral and Graph-Based Methods 

Early spectral methods evaluate features based on their ability to preserve local neighbor-hood structure. The Laplacian Score [4] assigns each feature a score based on its consistency with the graph Laplacian of the data, capturing local manifold structure but ignoring global variance. Multi-Cluster Feature Selection (MCFS) [5] extends this by solving a sparse spec-tral embedding and selecting features that best reconstruct the spectral coefficients. Joint 

ℓ2,1-norm methods [6] simultaneously perform row-sparse regression and graph-based mani-fold learning. While these methods elegantly capture local geometry, they share a common limitation: feature scores are computed in a single pass and do not account for redundancy between selected features. 

4.2. Sparse PCA and Soft Selection 

A separate line of work achieves implicit feature selection through sparsity regularization on PCA loadings. Sparse PCA (SPCA) by Zou et al. [8] reformulates PCA as a regression problem with LASSO penalties on the loadings, driving many loadings to zero. Jolliffe et al. [9] introduced SCoTLASS, which directly penalizes the ℓ1 norm of principal compo-nent coefficients. More recently, Yi et al. [10] proposed Adaptive Weighted Sparse PCA (AWSPCA), incorporating adaptive weights into the sparsity penalty to improve robustness to noise and outliers. Hu et al. [11] introduce an interpretable framework (SP-SPCA) with a single equilibrium parameter that adaptively adjusts variable penalties across components. In contrast, VPOS provides “hard” geometric selection rather than soft weighting. While SPCA and its variants produce sparse linear combinations (soft-scaling feature weights), VPOS selects a discrete index set S of original features. This is critical in interpretability-sensitive domains where any mixing of original variables is unacceptable. Furthermore, VPOS requires no sparsity penalty hyperparameters; its only hyperparameter is d, which has a clear geometric interpretation and is analyzed in Section 6.4. 

4.3. Reconstruction and Subspace Methods 

Reconstruction-driven selection minimizes data loss in the selected subset. Principal Feature Analysis (PFA) by Lu et al. [13] clusters the PCA loading vectors using K-means and selects the feature closest to each cluster centroid, effectively seeking diverse representatives of the loading space. VPOS can be viewed as a deterministic alternative to PFA: instead of a 6stochastic K-means pass, it uses greedy incremental orthogonal variance maximization with deflation to achieve a similar diversity objective with stronger theoretical guarantees and no randomness. Methods based on joint ℓ2,1 norms [6, 7] embed sparse regression within a graph Laplacian framework. Double-sparsity constrained methods [20] extend this by embedding sparsity constraints directly into the PCA framework. 

4.4. Matrix Factorization and Deflation Methods

VPOS, along with all methods in this subsection, can be understood as algorithmic approaches to (variants of) CSSP. The key distinctions among them lie in the operating space, the deflation mechanism, and the weighting scheme. The foundational algorithmic approach to CSSP is the Golub-Klema-Stewart (GKS) method [21], which applies pivoted QR factorization to the right singular vectors V⊤

Since pivoted QR is algorithmically equivalent to Gram-Schmidt orthogonalization with column pivoting (at each step, selecting the column with the largest residual norm after projecting out the already-selected subspace), GKS performs the same iterative deflation-and-select logic as VPOS. Recent work in optimal sensor placement extends GKS to Bayesian experimental design [22]. Boutsidis et al. However, GKS and RRQR-based methods operate on the unweighted right singular vec-tors Vk and target matrix approximation quality rather than feature selection; they have not been framed or evaluated as unsupervised feature selection methods. Their framework constructs a series of covariance matrices Σj by projecting the data onto orthonormalized function spaces, generalizing PCA to detect both linear and nonlinear redundancies. Their feature selection selects features based on diagonal elements of the iteratively deflated covariance matrix. VPOS is related in spirit but distinct in both mechanism and scope. Yaghooti et al. deflate the D × D covariance matrix by projecting the data distribution; VPOS deflates the D × d loading matrix via a right-multiplication null-space projection. This distinction has practical consequences: (1) VPOS operates in the compressed d-dimensional loading space, making it significantly cheaper when d ≪ D; (2) by explicitly weighting eigenvectors by √λk, VPOS scales the importance of each principal direction by its variance explained, giving B a direct spectral interpretation; (3) VPOS targets purely linear feature selection, making its guarantees cleaner and its output directly interpretable as row-norm maximization in a well-defined Euclidean space. 7How VPOS differs from standard CSSP algorithms. 6.1. Experimental Setup 

We conduct experiments on two types of datasets: (i) six real-world benchmark datasets spanning a broad range of sizes and complexities, from small tabular data to large-scale image collections and a gene-expression microarray, and (ii) two controlled synthetic datasets designed to stress-test the clustering trap and probe the D ≫ N regime.

This refines the characterisation: VPOS reliably achieves best reconstruction under the minimum-MSE rule even in the D ≫ N regime (provided d is chosen conservatively), but downstream classification performance depends on whether the data’s dominant variance directions coincide with discriminative structure.

6.6. Discussion 

The results identify three regimes for VPOS’s deflation mechanism: 15 Strong benefit: block-correlated features. When features cluster into groups driven by distinct latent signals, deflation prevents the selection budget from concentrating on the dominant group. The PCA (no deflation) baseline in Table 1 confirms this: at matched d,deflation reduces MSE by 10–73%, with the largest gains on CIFAR-10 and Breast Cancer. 

Modest benefit: moderate correlation. On Wine, correlation is moderate and no single factor dominates. VPOS still achieves the best MSE, but the margin over CSSP on 

X is narrow and Laplacian Score leads on kNN. Without a severe clustering trap, deflation has less to overcome. 

Structured D ≫ N : genomics with co-expression. Colon Cancer shows that VPOS can achieve best-in-class MSE even when the covariance is rank-deficient, provided the data has genuine pathway-level co-expression structure concentrated in a moderate number of principal components. The minimum-MSE rule selects d = 20 , which restricts deflation to the well-estimated portion of the loading space. The trade-off is visible in kNN: PCA without deflation achieves 87.2% vs. VPOS’s 71.0%, indicating that the MSE-optimal d overshoots the discriminative sweet spot. This is expected: VPOS optimises variance coverage, not class separability. Reconstructing the latent manifold is the primary objective, making downstream classification a secondary diagnostic rather than the goal function. While VPOS dominates on reconstruction fidelity across all datasets, the choice of using VPOS over alternative methods should be guided by the dataset at hand and the overall objective. A cross-cutting finding is the role of d and the importance of the minimum-MSE selection rule. On MNIST, kNN drops from 90.3% at d = 20 to 34.3% at d = 238 ; on Colon Cancer, from 82.1% at d = 15 to 61.2% at d = 34 . The underlying mechanism is the same: trailing principal components dominated by estimation noise corrupt the deflation. The minimum-MSE rule provides an automatic, reproducible guard against this failure mode — a simple sweep over 5–6 values of d suffices to identify the optimal operating point without requiring labels or external information. The HighDim synthetic result (Table 3) demonstrates that the minimum-MSE rule also resolves the previously-reported failure in the D ≫ N regime with unstructured redundancy. By selecting d = 20 rather than a large value near the rank limit, the rule restricts deflation to well-estimated directions, allowing VPOS to achieve the best MSE even with random redundancy. The kNN gap on this dataset (VPOS 38.0% vs. Laplacian Score 54.7%) confirms that variance-optimised selection does not guarantee classification performance when class structure occupies a different subspace. 

Why unsupervised? A natural question is why not use label information when it is available. Supervised filters (e.g., Fisher Score, mutual information) can exploit class struc-ture directly, and will often outperform unsupervised methods on classification-specific met-rics. However, the unsupervised setting is the appropriate framing for VPOS’s design goal: identifying features that faithfully represent the variance structure of the data regardless of a particular labelling. This is the relevant objective in exploratory analysis, multi-task set-tings where labels change across downstream tasks, and domains (e.g., unlabelled genomics cohorts, financial time series) where labels are unavailable or expensive to obtain. The kNN accuracy reported here serves as a downstream probe of whether variance-diverse features happen to capture discriminative structure — not as the optimisation target. 16 7. Conclusion 

VPOS unifies two well-studied ideas — greedy Gram-Schmidt selection and variance-weighted PCA representations — into a principled pipeline for unsupervised feature selec-tion. The key design choice is to apply the deflation in the compressed d-dimensional loading space rather than in sample space, and to weight eigenvectors by √λk so that directions ex-plaining more variance have proportionally more influence on selection scores. Each deflation step provably reduces the effective rank of B by one, the greedy objective is structurally connected to monotone submodular maximization with known approximation guarantees, and the selected features are original discrete variables — not linear combinations. Experiments across eight datasets spanning D ∈ [12 , 3072] — including full-scale MNIST, CIFAR-10, and a gene-expression microarray Colon Cancer confirm that VPOS with best-d

(selected by the minimum-MSE rule) achieves the lowest reconstruction MSE on all eight benchmarks. The PCA (no deflation) baseline — run at the same best-d — confirms that the deflation mechanism is the primary contributor, with deflation accounting for a 10–73% MSE reduction at matched d. The wall-clock timing results make explicit what the complex-ity analysis implied: operating in the compressed d-dimensional loading space makes VPOS 9–210 × faster than graph-based methods at large scale, while matching or exceeding their accuracy. The Colon Cancer result demonstrates that VPOS’s advantage extends to the ge-nomics setting that motivates much of the feature selection literature: even with D/N ≈ 32 ,VPOS achieves best-in-class MSE when the minimum-MSE rule selects a conservative d,exploiting the biological co-expression structure that concentrates signal in the leading prin-cipal components. The minimum-MSE selection rule resolves a previously-reported limi-tation: on the high-dimensional synthetic dataset, the rule selects d = 20 rather than a naive large value, allowing VPOS to achieve the best MSE even with unstructured redun-dancy. The results also sharpen the boundary conditions: VPOS is sensitive to d, and the minimum-MSE sweep is a necessary part of the pipeline — on MNIST, the gap between best-d (d = 50 ) and a naive large d is not marginal but categorical (87.8% vs. 34.3% kNN). The minimum-MSE rule optimises for variance coverage, which may diverge from classifi-cation performance when discriminative structure occupies a different subspace (e.g., Colon Cancer kNN: 71.0% at MSE-optimal d = 20 vs. 82.1% at d = 15 ; HighDim kNN: 38.0% vs. Laplacian Score’s 54.7%). This trade-off is by design: VPOS targets reconstruction fidelity as an unsupervised objective. Several directions remain open. Kernel extensions of the loading embedding could han-dle nonlinear inter-feature redundancy, which the linear framework misses by construction. Tighter bounds on reconstruction error as a function of k and d would provide principled d-selection rules beyond the empirical sweep. Regularised covariance estimation (e.g., Ledoit-Wolf shrinkage) would extend VPOS to the small-sample regime, potentially improving performance on datasets like Colon Cancer where N = 62 limits the loading quality. Evalu-ation on larger gene-expression compendia (e.g., TCGA pan-cancer, N > 10 ,000 ) would test whether VPOS’s advantage grows when covariance estimation is no longer the bottleneck. Finally, evaluating VPOS on deep feature representations — where spatial and semantic correlations are expected to be even denser — would determine whether the performance 17 advantage scales to modern representation learning settings.
