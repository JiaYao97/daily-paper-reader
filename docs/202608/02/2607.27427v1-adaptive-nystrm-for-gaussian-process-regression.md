## 摘要
高斯过程回归（GPR）是不确定性量化的一个稳健框架，但它的$O(n^3)$复杂度限制了其可扩展性。低秩Nyström近似可以将这一负担降至$O(nm^2)$，但其准确性在很大程度上依赖于地标点的选择。我们提出了一种自适应Nyström方法，它贪婪地选择地标点，以最小化核近似误差的迹残差。与静态近似不同，我们的方法将地标点扩展与超参数优化交织在一起，使得选择过程能够随着协方差结构的细化而自适应。在五个基准函数上的数值实验表明，该方法在准确性和稳定性方面都显著优于随机地标点选择。它获得了与精确GP推断相当的可预测性能，同时保持相对于样本量的线性扩展，为大规模计算机实验提供了一个原则性且高效的框架。

## Abstract
Gaussian Process Regression (GPR) is a robust framework for uncertainty quantification, yet its $O(n^3)$ complexity limits its scalability. Low-rank Nyström approximations can reduce this burden to $O(nm^2)$, but their accuracy depends heavily on the selection of landmark points. We propose an adaptive Nyström approach that greedily selects landmarks to minimize the trace residual of the kernel approximation error. Unlike static approximations, our method interleaves landmark expansion with hyperparameter optimization, allowing the selection process to adapt as the covariance structure is refined. Numerical experiments on five benchmark functions demonstrate that this method significantly outperforms random landmark selection in both accuracy and stability. It achieves predictive performance comparable to exact GP inference while maintaining linear scaling with respect to the sample size, providing a principled and efficient framework for large-scale computer experiments.

- **核心问题**：高斯过程回归（GPR）尽管在不确定性量化和非线性建模方面表现出色，但其核心计算过程（核矩阵求逆/Cholesky分解）需要 \(O(n^3)\) 时间，严重限制了其在大规模数据集上的应用。

- **论文目标**：提出一种**自适应Nyström方法**，通过贪心选择地标点来最小化核近似误差的迹残差，并将地标选择与超参数优化交替进行，从而在保持线性扩展的同时逼近精确GPR精度。
- **整体意义**：为大规模计算机实验提供了一种兼顾效率与稳定性的GPR求解框架，推动了低秩近似方法在统计建模中的应用。

## 2. 方法论：核心思想、关键技术细节、公式与算法流程

### 核心思想
- 使用Nyström低秩近似代替完整核矩阵，并通过**贪心准则**逐步添加地标点，使近似误差的迹（trace residual）不断减小。
- **创新点**：将地标扩展与超参数估计**交织进行**，使得地标选择随协方差结构变化而自适应调整，而不是在固定核参数下一次性完成。

### 关键技术细节
- **Nyström近似**：选取 \(m\) 个地标点 \(Z = \{z_1,\dots,z_m\}\)，定义交叉核矩阵 \(C = K_{XZ}\) 和地标核矩阵 \(W = K_{ZZ}\)，则 \(\tilde{K} = C W^{-1} C^\top\)。
- **Woodbury化简**：近似协方差矩阵 \(\tilde{R} = \tilde{K} + \eta I\) 的逆和行列式可通过Woodbury恒等式及矩阵行列式引理在 \(O(nm^2 + m^3)\) 内求得。
- **迹残差准则**：每个点 \(x_i\) 的残差方差定义为：
  \[
  r(x_i) = K(x_i, x_i) - k_Z(x_i)^\top W^{-1} k_Z(x_i)
  \]
  其中 \(k_Z(x_i)\) 为 \(x_i\) 到各地标点的核向量。该值对应GP先验在给定地标信息下的条件方差，总近似误差为 \(\text{tr}(K - \tilde{K}) = \sum_{i=1}^n r(x_i)\)。
- **贪心选择**：每一步选择当前残差最大的点作为新地标：
  \[
  x^* = \arg\max_{x_i \notin Z} \left(1 - \|L_W^{-1} k_Z(x_i)\|^2\right)
  \]
  这与核矩阵的列主元Cholesky分解等价，但该迭代过程会同步更新超参数。

### 算法流程（Algorithm 1）
1. 从训练集中随机初始化 \(m_0\) 个地标点。
2. 使用BOBYQA优化器最小化Nyström负对数边际似然 \(\tilde{L}_m(\theta,\eta)\)，得到初始超参数。
3. 迭代执行以下步骤直到收敛（\(t = 1,2,\dots\)）：
   - 用当前超参数计算所有非地标点的残差 \(r(x_i)\)。
   - 选取残差最大的点加入地标集合。
   - 重新优化超参数（以上一次估计为初值）。
   - 判断收敛条件：相对超参数变化 \(\Delta_\theta < \delta_\theta\) 且平均迹残差 \(\bar{r} < \delta_r\)。
4. 最终计算方差 \(\hat{\tau}^2\) 和均值系数 \(\hat{\beta}\)，返回参数和地标集合。

### 复杂度
- 每次似然评估：\(O(nm^2 + m^3)\)。
- 整体算法：\(O(T \cdot E \cdot nm^2)\)，其中 \(T\) 为地标更新次数（实验中通常小于20），\(E\) 为每次优化的似然评估次数（约100–300）。
- 对 \(n \gg m\)，算法规模与 \(n\) 呈线性关系，远优于精确GPR的 \(O(n^3)\)。

## 6. 主要结论与发现

- **自适应选择显著优于随机选择**：在绝大多数场景下，自适应Nyström的S-RMSPE明显低于同等数量地标的随机Nyström，且标准差更小，表明其预测更稳定、更少受初始地标随机性影响。
- **接近精确GP精度**：举例来说，Borehole函数常数均值情形下，自适应方法仅需35个地标（3.5%的样本）即可匹配全GP的预测误差；Steel Column多项式均值情形下自适应方法S-RMSPE为 \(2.79\times10^{-7}\)，几乎与全GP的 \(2.09\times10^{-7}\) 持平。
- **地标数量自适应调节**：多项式均值模型通常需要更多地点才能收敛，说明算法能感知模型复杂度。
- **计算效率**：在较大样本（如 \(n=1000\)）时，自适应方法能显著节省时间（如Steel Column从879秒降至174秒），并保持线性扩展。
- **例外情况**：Wing Weight函数多项式均值下随机Nyström略优于自适应，说明在高维且强全局趋势时，均匀采样可能偶然覆盖更好地全局回归系数；OTL Circuit多项式均值下自适应方法（30.66秒）比全GP（23.28秒）更慢，说明小样本时顺序优化的开销可能超过单次求逆成本。
