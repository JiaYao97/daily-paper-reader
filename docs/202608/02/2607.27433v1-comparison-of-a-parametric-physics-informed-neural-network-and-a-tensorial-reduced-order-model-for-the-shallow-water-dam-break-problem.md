## 摘要
我们开发了两种参数化数据驱动降阶模型：物理信息神经网络（PINN）和非侵入式张量降阶模型（TROM），并将这两种方法应用于参数化的一维浅水溃坝问题。两种降阶模型均不需要时间积分，而是学习从空间、时间和溃坝参数到物理状态的直接解映射。我们对样本外和 extrapolated 参数值进行了详细比较。此外，我们证明了引入冲击感知配点对于提高 PINN 模型的鲁棒性至关重要。

## Abstract
We develop two parametric data-driven reduced models: a physics-informed neural network (PINN) and a non-intrusive tensorial reduced-order model (TROM), and apply both approaches to the parametrized one-dimensional shallow-water dam-break problem. Both reduced models do not require time integration and learn a direct solution map from space, time, and dam-break parameters to the physical state. We present a detailed comparison for out-of-sample and extrapolated parameter values. In addition, we demonstrate that it is essential to introduce shock-aware collocation to improve the robustness of the PINN model.

## 1. 论文的核心问题与整体含义

- **研究背景**：浅水方程（SWEs）是典型的双曲守恒律系统，其解常含有激波、移动前沿等间断结构。溃坝问题（Dam-Break Problem）作为经典基准问题，在实际工程（如洪水预警、不确定性量化、实时预测）中具有重要应用价值，但其激波特性给传统数值离散和降阶建模带来了双重挑战。
- **核心问题**：传统全阶模型（FOM）需要时间积分，计算成本高昂；而基于投影的降阶模型（ROM）在处理含激波的传输主导问题时面临 Kolmogorov n-width 缓慢衰减的困难。因此，论文的核心问题是：**如何构建无需时间积分、能直接在参数空间中泛化的参数化降阶模型，以高效且准确地预测不同参数组合下的溃坝流场？**
- **研究意义**：论文系统比较了两种范式——基于神经网络的 PINN 与基于张量分解的 TROM——在参数化浅水溃坝问题上的表现，为该类含激波双曲问题的代理建模提供了系统性参考。

## 2. 论文提出的方法论

### 2.1 问题设定
- 控制方程为 1D 浅水方程（守恒形式）：∂ₜU + ∂ₓF(U) = 0，其中 U = (h, q)ᵀ，h 为水深，q = hu 为流量（动量）。
- 参数化初始条件：溃坝位于 x_dam = L/2，参数向量 μ = (h_L, h_R) 分别表示上游和下游初始水深，涵盖干河床（h_R = 0）和湿河床（h_R > 0）两种物理 regime。
- 目标：学习参数到解的映射 S: (x, t, μ) ↦ U_FOM(x, t; μ)，使得对新参数值可直接预测任意时刻的解。

### 2.2 PINN 方法
- **网络结构**：全连接前馈网络，输入为 (x, t, h̄, γ)，其中 h̄ = (h_L + h_R)/2、γ = (h_L − h_R)/(h_L + h_R + ε) 为重新参数化后的输入；输出为 (h_θ, u_θ)。网络含 5 个隐藏层、每层 120 个神经元，SiLU 激活函数，共 58,922 个可训练参数。
- **物理约束**：采用守恒形式的强残差——质量残差 R₁ = ∂ₜh_θ + ∂ₓ(h_θu_θ) 和动量残差 R₂ = ∂ₜ(h_θu_θ) + ∂ₓ(h_θu_θ² + ½gh_θ²)。通过自动微分计算导数。
- **损失函数**：加权组合，包含数据损失、PDE 残差损失、边界条件损失、初始条件损失和非负性惩罚。关键设计包括：
  - **激波感知配点**：根据 FOM 数据估计激波位置 x_sh(t; μ)，在激波附近设置宽度为 w_excl = 2.5 的排斥带，避免在非光滑区域放置配点。
  - **EMA-RMS 残差缩放**：使用指数移动平均的均方根值对两个残差分量进行归一化，平衡量级差异。
  - **PDE 门控**：根据梯度大小和预测水深动态调整配点权重，在陡峭梯度和近干河床区域减弱强形式残差的惩罚。
  - **训练策略**：Adam 优化器，学习率 10⁻³，余弦退火，梯度裁剪，损失权重 warm-up（前 1/4 训练周期线性增加到目标值）。
- **物理量一致性**：网络预测原始变量 (h, u)，但通过 q_θ = h_θu_θ 形成的守恒量来施加 PDE 约束，保持与数据格式一致。

### 2.3 TROM 方法
- **张量表示**：将 FOM 快照组织为四阶张量 Q_φ ∈ R^{N_x × N_L × N_R × N_T}（空间 × h_L 参数 × h_R 参数 × 时间）。
- **HOSVD 压缩**：对每个模态的展开矩阵做 SVD，按能量准则（阈值 ε = 10⁻³）选取多线性秩 (Ñ_x, Ñ_L, Ñ_R, Ñ_T) = (94, 4, 5, 21)。
- **非侵入式推理**：对新参数 μ*，使用三次样条插值计算参数网格上的插值系数，然后通过 Tucker 张量沿参数模态收缩，重建解矩阵。整个过程无需时间积分。

## 3. 实验设计

- **基准问题**：1D 溃坝问题，计算域 Ω = [0, 100]，最终时间 T = 2.5。
- **数据集**：采用局部 Lax-Friedrichs 有限体积法生成 FOM 数据。参数网格为 (N_L × N_R) = (5 × 13) = 65 个参数组合，h_L ∈ {10, 14.5, 19, 23.5, 28}，h_R ∈ {0, 0.1363, ..., 8}（13 个非均匀分布值）。空间网格 N_x = 402（含 2 个 ghost cell），时间步长 Δt = 10⁻⁴，快照间隔 Δt_s = 0.1，共 25 个时间快照。
- **评估指标**：相对 L₂ 误差（水深受度 h 和流量 q 分别计算）。
- **插值实验**：6 个样本外参数组合：(12,0)、(12,7)、(15,4)、(18,0)、(26,0.14)、(26,7)，在 t = 0.5、1、1.5、2 进行评估。
- **外推实验**：6 个超出训练范围的参数组合：(9,4)、(20,8.5)、(29,4)、(32,4)、(29,8.5)、(32,10)，在 t = 2 评估。
- **消融实验**：围绕参考配置进行“单因子变量”消融，共 8 个配置（baseline + 7 个变体），在 99 个随机采样的参数实例上计算时空相对 L₂ 误差的均值。
- **对比方法**：同一数据集上训练的 PINN 与 TROM。已有相关工作中对 FOM 的验证作为参考基线。

## 4. 资源与算力

- **实验数量**：
  - 插值实验：6 个参数组合 × 4 个时间点，包含干河床、湿河床、近干河床多种 regime；

  - 消融实验：7 个变体 + 1 个 baseline，每个变体在 99 个随机参数上评估；

  - **优点**：实验覆盖了插值、外推、消融三个维度，参数 regime 涵盖干/湿/近干河床，对比维度较全面；消融实验设计采用“单因子变量”法，归因清晰；两种模型使用同一数据集和同一指标，对比公平。
  - **不足**：插值实验仅 6 个参数组合，统计代表性有限；外推实验仅在 t = 2 单时间点评估；消融实验的 baseline 与最终模型有微调（减少 epochs、延长 ramp-up），可能不完全代表最终配置的表现。

## 6. 论文的主要结论与发现

- **两种模型均有效**：TROM 和 PINN 在训练参数域内的插值预测均达到较低误差，能准确定位激波位置，最大误差集中在移动间断附近。
- **regime 依赖性**：TROM 在干河床情形更准确，PINN 在湿河床（较大 h_R）情形更准确；近干河床 regime（h_R = 0.14）对两者都是最大挑战。
- **外推能力**：PINN 在所有外推案例中均优于 TROM，且随着外推距离增大优势更明显。TROM 在 h_L > 28 时在激波附近产生伪凸起，源于其基于插值的构造。
- **激波感知配点至关重要**：消融实验表明，移除激波感知配点使聚合误差从 2.494×10⁻² 升至 7.839×10⁻²（超过 3 倍），是影响最大的设计选择；PDE 门控和残差缩放次之。
- **频谱偏置缓解**：PINN 在大多数情况下能准确再现解的频谱，主要偏差出现在近干河床的高波数尾部。
- **局限性**：两种模型在激波离开计算域的时刻（如 μ = (26, 0.14), t = 2.5）均无法准确预测右边界附近的解。

## 7. 优点

- **方法创新性**：直接学习参数到解的映射、完全避免时间积分的降阶建模思路清晰，对比了两种截然不同的技术路线（神经网络 vs 张量分解）。
- **激波感知配点策略**：针对含激波双曲问题提出的“避开激波核”而非“在激波处用力”的策略，通过消融实验证明了其必要性，为 PINN 处理间断问题提供了实用方案。
- **详尽的消融研究**：系统考察了 7 个关键设计组件的贡献，识别出最重要的因素（激波感知配点 > 残差缩放 > PDE 门控），具有重要工程指导意义。
- **公平对比**：两种模型使用相同的训练数据、相同的评估指标和相同的评估参数集，对比结论可信度高。
- **综合评估维度**：不仅比较点态误差，还进行了频谱分析、参数外推测试、计算成本对比，视角全面。
- **讨论深入**：对两种模型的优缺点、适用场景、扩展性进行了细致的定性分析，并给出了改进方向。

## 8. 不足与局限

- **近干河床外推失效**：在 h_R 接近 0 时，湿/干河床之间的 regime 转变导致解对参数的非光滑依赖，两种模型在该区域误差均显著增大，且对激波离开计算域的情形缺乏有效应对。
- **评估规模有限**：插值实验仅 6 个参数组合、外推实验仅 6 个参数组合且仅在 t = 2 评估，统计效力有限；未报告多次训练随机种子的方差。
- **PINN 训练开销大**：训练需数小时（20 小时 CPU），超参数众多（激波跟踪、门控阈值、EMA 参数等），调参成本高；TROM 的离线阶段虽然快，但其误差主要依赖 FOM 快照的覆盖质量。
- **TROM 的适用性限制**：需要矩形张量积参数网格，无法直接处理非结构化或不规则采样的参数空间；单一新的 FOM 解无法直接纳入现有张量表示。
- **PINN 的扩展挑战**：扩展到 2D/3D 时需跟踪多维激波且训练成本急剧增加，论文未给出具体实验证据。
- **强形式 PDE 残差的固有问题**：虽然激波感知配点缓解了问题，但强形式残差在间断附近本质上不适用，弱形式/积分形式的 PINN 变体未被纳入比较。
- **超参数敏感性未充分讨论**：除消融实验的单因子分析外，未系统评估超参数（如网络宽度、深度、学习率）的敏感性。
